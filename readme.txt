# Recetas y Pico

Recetas y Pico es una web que recopila las recetas de mi hogar.
La web es sencilla y práctica. Es como un libro de recetas de mis padres, pero en formato web.
Las fotos son un poco cutre, a ver si cambio de móvil.

---

## ⚡ Tecnologías usadas

- **Eleventy (11ty)**: Generador estático de sitios.
- **HTML / CSS / JS**: Estructura y estilo de la web.
- **JSON**: Datos de recetas y categorías.
- **cwebp**: Conversión de imágenes a WebP para optimizar carga.
